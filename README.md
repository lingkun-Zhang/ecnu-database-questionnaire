## 停止与再次启动（Windows）

不再使用时双击 `Stop.cmd`。它先让本项目后端正常退出，再正常关闭本项目MongoDB；账号、问卷、答卷、数据目录和`.env`都会保留。重复停止可以正常完成。之后再双击`Start.cmd`即可继续使用原数据；重复启动会复用已经识别的本项目服务。

关闭浏览器标签页不会停止后台服务。启动、停止会检查进程的实际路径、启动时间、实例标识和数据库目录；端口属于其他程序或记录无法确认时，会返回失败并保留现场，不按进程名称猜测归属。日志仍在`.runtime/`。

命令行可执行：

```powershell
# 启动但不自动打开浏览器
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -NoBrowser

# 正常停止后端及项目MongoDB
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1
```

停止脚本默认等待每个已识别进程最多30秒；后端没有正常退出时，不强制结束它，也不继续关闭数据库。以上入口使用Windows PowerShell 5.1；启停互斥与控制文件都仅作用于当前项目。`.runtime/backend.instance.json`和`backend.stop.json`是短期本地控制记录，不属于提交材料或公开API。

## 从源代码准备环境

需要 Windows、Python 3.12+、Node.js 20.x（至少20.19）或22.12+、MongoDB 与 mongosh。当前实测环境为 Python 3.12.14、Node.js 24.18.0、MongoDB 6.0.29、PyMongo 4.19.0；依赖锁定在 requirements.txt 和 frontend/package-lock.json。

双击 `Install.cmd` 安装锁定依赖、生成本机配置、检查前端类型并构建。复制到其他电脑时重新建立 `.venv`，不依赖本机虚拟环境的绝对路径。Python启动器没有登记合适版本时，可运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -PythonExe "实际的python.exe路径"`。安装器先核对Python/Node版本；已有不合要求的虚拟环境不会被自动删除。

MongoDB 与 mongosh 应加入 PATH；也可显式运行 `scripts/mongo.ps1 -Mongod 路径 -Mongosh 路径`。

常用操作：

```powershell
# 初始化项目独立的MongoDB副本集
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/mongo.ps1

# 生成本地配置（已有配置会保留）
.venv\Scripts\python.exe scripts/setup.py

# 启动后端并同时提供已构建的页面
.venv\Scripts\python.exe scripts/run.py

# 运行真实数据库测试，使用自动生成的独立测试库
.venv\Scripts\python.exe -m pytest -q

# 前端开发：另外打开一个终端
cd frontend
npm ci
npm run dev

# 前端会话隔离回归（已安装前端依赖后执行）
npm run test:session

# 编辑错误定位与JSON结构保护回归
npm run test:editor

# 条件编辑、会话和错误定位的相关前端回归
node --test tests/conditionEditor.test.cjs tests/session.test.cjs tests/editorErrors.test.cjs

# 设计提示纯逻辑及真实数据库/API专项（回到项目根目录）
cd ..
.venv\Scripts\python.exe -m pytest tests/test_domain.py tests/test_design_checks.py tests/test_design_checks_api.py -q

# 启停控制与进程归属测试（不操作真实运行服务）
.venv\Scripts\python.exe -m pytest tests/test_runner_control.py tests/test_lifecycle_scripts.py -q -s

# 成功提交标识的内容、版本、等价恢复及并发边界（真实隔离测试库）
.venv\Scripts\python.exe -m pytest tests/test_submission_boundaries.py -q -s
```

API 文档位于 `http://127.0.0.1:8000/docs`，健康检查位于 `/api/health`。开发前端通过 Vite 把 `/api` 请求转发给 8000 端口。
