主代理实现配置、认证、仓储、服务事务、API、运行脚本、API 测试及检查点材料。子代理分别实现领域引擎与单测、MongoDB 校验器与统计及恢复测试、Vue 页面。

给领域子代理的核心提示：

给前端子代理的核心提示：

> Vue3和TypeScript，真实API驱动账号、问卷编辑、规则预览、发布版本、填写回改、统计明细与导出，不引入现成问卷引擎。

这些是代理任务提示的摘录，不冒充用户输入或完整对话转录。

### 发现的问题与改动

- AI 生成的首次回执使用微秒时间，数据库读回只有毫秒；真实重放断言失败后，AI 统一精度并回归通过。
- AI 的严格整数判断未兼容 BSON Int64；审阅发现后，AI 修改类型判断并加入真实 BSON 回归。
- AI 修正潜在配置对象 repr 泄露，密钥字段不出现在调试展示中。
- 初始环境创建缺少 pip 引导文件；使用已提供运行时仅为项目独立环境安装依赖，未修改全局 Python 包。
- 指定目录的 Windows PowerShell 5 启动检查暴露原生命令错误与引号传递差异；AI 修复探测、引号与脚本编码后，实际启动及健康检查通过。

77 项测试和63个subtest通过，前端类型与构建通过；原始证据见 test-report.md 与 evidence/。未完成浏览器、性能或干净安装验收。
