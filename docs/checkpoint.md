## 实测发现并修复

1. 首次返回时间保留微秒、MongoDB 重放时间为毫秒，导致同一回执主体不完全一致。统一服务端时间到 BSON 毫秒精度，发布和提交重放用例通过。
2. BSON Int64 是 int 子类，早期严格类型判断会拒绝读回的大整数配置。领域层接收整数子类并排除 bool，增加真实 BSON 编解码回归。
3. 测试上下文可能显示配置对象，因此密钥字段关闭 repr；异常接口只返回稳定业务错误，不返回连接串或密钥。
4. 目标目录启动检查发现 Windows PowerShell 5 的原生命令错误与引号传递差异；修正探测和脚本编码后，指定目录中的 MongoDB 与后端成功启动，健康检查通过。
