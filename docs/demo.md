# 第一阶段安装与演示步骤

本阶段只实现初始任务书，不包含第二阶段新增需求。演示用教学数据，不代表真实用户规模。

## 1. 安装与启动

准备Python 3.12+、Node.js 20.19+或22.12+、MongoDB与mongosh。将源码解压到新目录后双击Install.cmd，再双击Start.cmd；浏览器访问http://127.0.0.1:8000。Stop.cmd用于正常关闭，保留数据。

如果Windows的py启动器没有登记正确版本，可在项目目录明确指定Python：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -PythonExe "C:\Python312\python.exe"
```

上述路径是填写方式示例，应换成实际已安装的python.exe。安装器会检查Python/Node版本，不删除不合要求的旧虚拟环境。首次生成.env及稳定密钥，后续保留；MongoDB使用单节点副本集支持事务。API文档位于http://127.0.0.1:8000/docs。

## 2. 从空白创建并演示四种题型

1. 注册并登录自己的教学账号，创建“第一阶段验收问卷”。
2. 点击数字填空，题名“年龄”，必答，0—120、仅整数。
3. 添加单选“身份”，选项“学生”“工作人士”，必答。
4. 添加多选“兴趣”，选项“阅读”“运动”，快捷设置恰好2项。
5. 添加文本“建议”，最少2字、最多20字，必答。
6. 编辑年龄题：添加“小于18→兴趣”的条件，默认去身份；其他默认去向沿添加顺序，文本结束。
7. 保存草稿，刷新重新打开，核对题目和配置；收集设置允许同人多填，保存后发布V1，打开真实填写链接。

## 3. 两份实际填写与预期

| 操作 | 预期 |
|---|---|
| 年龄121并继续 | 提示超出范围，不能进入下一题 |
| 改17并继续 | 直接进入兴趣，跳过身份 |
| 兴趣只选阅读 | 提示数量不符；再选运动可以继续 |
| 建议填“好” | 提示文本长度不符；改“很好”，匿名提交成功 |
| 再次填写年龄18 | 进入身份，选学生；两项兴趣、建议“增加实践机会”，取消匿名并提交 |

创建者查看统计：2份答卷、1位参与者、匿名1份；年龄总和35、均值17.5；身份到达1份、跳过1份，学生1次；兴趣两选项各2次；两段原始建议完整展示。切换单题“身份”后只列一份有效回答。

这条流程已在干净安装实例实际完成，页面记录及截图见evidence/final-demo-*，不是只列计划。

## 4. 一键导入六份可核算样例

在新教学环境中启动应用后运行：

```powershell
.venv\Scripts\python.exe scripts/seed.py
```

非默认端口时追加`--base-url http://127.0.0.1:端口`。脚本通过真实API导入，保留已有数据；默认教学账号为demo_owner / DemoLab2026!，不用于真实部署账号。脚本对本地API直接连接，不读取系统HTTP代理。

预期6份答卷、5位参与者、匿名/实名各3份；评分有效5份，含0，总和28、均值5.6，多选阅读/运动/音乐各3次。脚本及这些核算已在干净实例验证，见evidence/final-seed-20261021.txt和final-sample-checks-20261021.json。

## 5. 最终验证与范围

验收目录起初没有.env、.venv、node_modules、dist或运行数据；重新安装依赖、生成配置、构建，并在新随机数据库从零演示。沿用了本机Python/Node/MongoDB程序和正常包缓存，不称作重装操作系统。为隔离原演示数据，验收使用临时本地端口及新逻辑数据库；测试库已清理。

最终自动回归为162项后端通过、251个subtest通过、3项Windows符号链接权限相关测试跳过；前端43项通过，类型检查/构建通过。原始日志、XML及文件清单随源码提交。
