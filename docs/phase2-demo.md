# 第二阶段演示步骤

整理日期：2026年10月28日。本文是按当前界面与接口编写的复现指南，不是一次新的浏览器执行记录。已经实际执行的范围和证据列在文末；2026年10月27日的测试结果保留原日期。

## 准备与演示数据

先按[安装与启停](../README.md)安装、启动当前第二阶段代码，再打开本机工作台。已有环境应保留配置和数据，不为演示清空数据库。另注册两个仅用于教学的账号，以下称“作者”和“接收者”；账号名、密码由演示者自己设置，不填写个人资料。切换账号可以使用两个独立浏览器会话，也可以保存后退出、重新登录。

下列三个场景分别使用不同的独立题目，避免前一个场景的历史发布和答卷混入后一个场景的预期数字。各场景从尚未使用过的新题目开始，问卷名称也加本次演示标识。题目内容版本V1、V2与问卷发布版本V1、V2是两套编号，应分别查看。

| 场景 | 独立题目 | 问卷与预期 |
|---|---|---|
| 版本与题库 | “版本演示评分”，数字V1为0—7整数 | 作者的A固定题目V1，B固定题目V2；分别填0、3 |
| 共享与汇总 | “共享演示评分”，数字V1为0—100整数 | 作者的C与接收者的D都固定题目V1；分别填0、3 |
| 路径统计金样 | “路径演示评分”，数字V1为0—1000整数 | 作者的E、F共五份答卷，核对R8/V6/A5/U1/S2 |

实际填写必须登录。一个账号需要给同一问卷提交多份时，在第一份答卷之前，到“收集设置”开启“允许同一个人多次填写”并保存；收到首份正式答卷后该政策锁定。预览回答只在页面求值，不会产生正式答卷，统计数字必须来自实际填写并提交成功的回执。

## 一 固定版本、题库与恢复

1. 作者进入侧栏“题目管理”→“我的题目”→“新建题目”，建立“版本演示评分”，题型选数字，最小值0、最大值7，勾选“只接受整数”，保存为题目V1。必答和跳转在各问卷内配置，不保存在通用题目内容中。
2. 进入“题库”，新建一份演示题库，用“收录已有题目”明确选中刚才的V1。记下成员所示“题库固定V1”。
3. 新建作者问卷A，从“从已保存题目选用”打开窗口，切至“从题库选择”，查看并选择“题库V1”。保存草稿、发布问卷第一版。A此时固定题目V1。
4. 返回题目管理，选中题目V1，点击“基于此版编辑”，将范围改为1—5整数。点击“检查影响并保存新版本”：应看见A的已保存引用及检查时间。先取消检查，确认仍无题目V2且编辑值保留；再次检查并明确确认创建，才生成题目V2。已有A和题库成员仍保持V1。
5. 在题库对该成员选择“更新所用版本”，明确选题目V2。新建作者问卷B，从题库选用V2，保存并发布。A不随题库更新，B固定V2。
6. 打开A实际填写页，匿名提交0；打开B实际填写页，先输入0，页面应提示超出当前范围且不能继续；改为3并提交。此处的0校验发生在继续填写步骤，不能将它记成提交接口实际拒绝了0。单卷“统计与回答”应分别显示A的0、B的3。
7. 返回题目管理，选历史V1并点击“恢复此版内容”。检查阶段先取消一次，版本数不增加；重新检查并确认后形成V3，其内容与V1一致，当前头为V3，历史保留V1/V2，恢复记录标明内容来源及恢复前当前版。A仍V1、B仍V2，恢复不会让旧问卷自动换版。
8. 演示题库归档并确认，在问卷选题窗口不能从归档库选题；恢复题库后成员仍固定V2。先取消“移出题库”，刷新后成员仍在；再确认移出，成员消失，但独立题目、A/B的固定来源、已发布内容和答卷仍保留。不要用删除问卷代替移除成员。

作者在“使用情况”可分别查询当前草稿、发布快照及题目系列/具体版本。同一问卷可能同时有草稿和多个发布快照，不能将这些行数相加称为不同问卷数。

从该题进入“跨问卷统计”，选择“全部版本，分别汇总”并获取范围。预期题目V1有A的0，V2有B的3，各自A=1、总和分别0和3；恢复后的V3没有发布来源，不因当前头是V3就凭空出现答卷。系统不提供把V1/V2混成一个平均分的结论。

## 二 共享撤销、他人影响和独立统计授权

1. 作者新建独立的“共享演示评分”V1（0—100整数），在共享管理输入接收者的准确账号名，授予题目使用权。作者新建C，接收者新建D，各从本人/“共享给我的”列表明确选这道题V1，保存、发布；此时先不填写D。
2. 接收者查看共享题，应能只读查看版本并在自己的问卷选用，不能编辑原题、恢复原题或转授权。作者的“使用情况”只展示本人的C；不能因此认定D未引用。
3. 作者基于这道题V1编辑题干，打开影响检查。本人条目显示C标题；他人条目应以稳定脱敏代号表示D的引用，不显示D真实标题、账号、链接或答案。先取消，版本仍为V1；再检查并确认生成V2，C/D均继续固定V1。
4. 作者点击“撤销共享”，先取消，核对授权修订未改变；再次明确确认撤销。接收者重新读取后不能新增该题实例、在新卷引用或更换版本。D服务器当前草稿已保存的同一固定绑定可以保留；关闭不可读取的来源窗口不应自动解绑。
5. 接收者仅修改D问卷说明，保存草稿并再次发布，原题仍为V1；随后实际匿名提交3。作者给C实际匿名提交0。D最初发布版可以没有答卷，不能要求发布来源数恰好等于两份；这里核对的是两份来源问卷、两份有效实例答案。不要再额外提交试填值，以免改变以下数字。
6. 作者从该题打开“跨问卷统计”，选择全部版本/全部填写方式并“获取新范围”。此时D尚未授权汇总，结果仅含本人的C：V1有效作答A=1、sum=0、avg=0。题目使用共享以及撤销操作本身都不授予统计权限。
7. 接收者打开D编辑器→“收集设置”→“向题目作者提供统计汇总”。先取消一次“授权统计汇总”，状态应不变；再确认授权。作者明确点击“刷新并获取新范围”，新范围V1应有两份来源问卷、两份答卷，R=V=A=2、U=S=0、sum=3、avg=1.5、min=0、max=3，直方图次数之和为2。
8. 作者“读取明细”后只见本人C的0；D只作为概括的授权汇总来源出现。导出“本人明细CSV”也只能覆盖C，不能为了与汇总A=2对齐而包含D的3、答题者身份或其他题答案。实际复演下载时应自己打开文件核对；历史浏览器证据没有独立检查下载文件内容。
9. 接收者明确撤销D统计授权。作者对旧范围的后续读取应提示范围失效，再明确获取新范围后仅含C、sum=0。重新授权后仍须获取新范围，旧范围不会因重授而复活。撤销前已经执行中的读取及已经看到或保存的汇总无法保证被即时收回。
10. 将作者页的填写方式改为“仅实名填写”，未刷新前应仍标明原范围、提示筛选尚未应用；明确获取新范围后是零份实名答卷、空明细及无平均值。匿名0是有效答案，不等于空答案。

若要展示恢复使用共享，可由作者明确“重新启用”，接收者重新读取后才能在另一个新草稿选V2；这会增加引用，需在上述数字核对结束后再做。统计授权仍由各问卷所有者逐题决定，不随使用共享启用自动增加。

## 三 可选的路径与固定范围金样

本节使用第三道新题，不沿用C/D数据。它对应真实后端测试的五份来源答卷金样，可用于讲清MongoDB聚合的输入和计数单位；本轮没有新做这一整组浏览器操作。

1. 作者新建“路径演示评分”V1（0—1000整数）。E两次选用同一版本，两个卷内实例在本节记为e1、e2，e1必答、默认转e2；e2选填、默认结束。给e1设置“≥30时直接结束”的规则。界面生成的实例ID无须改成这两个记号，应根据题目位置辨认。
2. F先建一道本地单选入口“参与评分？”，选项是/否，默认到固定V1的评分实例；“否”以单选“等于选项”的规则直接结束。E/F均在第一份提交前开启允许多次填写，保存并发布。
3. 按下表依次真实提交；“未到达”表示页面未进入该实例，不能把它当作经过后留空。

| 问卷与序号 | 填写输入 | 填写方式 |
|---|---|---|
| E第1份 | e1=0、e2=10 | 匿名 |
| E第2份 | e1=20、e2留空 | 实名 |
| E第3份 | e1=30、e2未到达 | 匿名 |
| F第1份 | 是、评分40 | 实名 |
| F第2份 | 否、评分未到达 | 匿名 |

4. 从独立题目进入跨问卷统计并获取范围，来源应分别固定E截至提交序号3、F截至2。该版本有五份来源答卷、四份至少作答；R=8次机会、V=6次经过、A=5次有效作答、U=1次经过未答、S=2次跳过，sum=100、avg=20、min=0、max=40。明细五个数值为0、10、20、30、40，直方图次数和为5。
5. 保留这个范围，再给F新增“是、999”一份。旧范围仍应是上述数值；明确刷新获取新范围后，F截至3，R/V/A/U/S变成9/7/6/1/2、sum=1099。E截至3不能成为所有问卷共用的上界，否则F新序号3会错误混入旧范围。

这些R/V/A/U/S是题目实例机会、路径及作答次数，不是跨问卷唯一人数。同一答卷可以对同题两处实例作答，A增加2但来源答卷只增加1；不同版本的人数也不能直接相加。
