# 题库管理与从题库选题界面

记录日期：2026年10月26日至27日。从本地提交 `e81056d` 的[题库后端](phase2-question-banks.md)继续，第一阶段基线仍为 `99b66d1e637fa3b4ecb13719c0230ecb7e958701`。本步将已有题库契约接入Vue界面，不新增业务API，不调整MongoDB schema，也不改变问卷的来源字段。

## 本步范围与操作流程

侧栏新增独立的“题库”页面，用于创建私有题库、编辑名称与说明、查看使用中或已归档的题库，并管理固定版本成员。已有“题目管理”继续管理独立题目及其历史、共享和使用情况；两个页面各自承担实际用途。

题库成员显示“题库固定V几”，作者当前版本与条目不同则提示已有其他当前版本。提示不代替选择：收录时明确选择一个版本，更新条目时只在同一题目系列中重新选版。题库更新不会自动更换已经保存到问卷的引用，也不修改旧发布快照或答卷。

问卷编辑器仍从“从已保存题目选用”打开窗口，窗口增加“题目列表”和“从题库选择”两个来源。题库选择器列出未归档题库，只展示并允许选择当前可用的成员；已有引用换版时还锁定原题目系列，不允许借题库把另一道题替换进来。选择结果继续交给现有 `applyQuestionVersion` 和 `questionSources` 处理，保留卷内实例ID、必答和跳转设置，仍需保存草稿并发布。

题库内的收录、换版窗口复用现有题目版本选择器，通过 `destination=bank` 区分题库用途；普通收录、同系列换版及来源不可读时的提示均按题库场景显示。该内层窗口支持关闭按钮、背景点击及Escape，关闭方法继续检查忙碌与子组件离开保护。

归档、恢复、移出题库和结束待处理请求使用页内确认，显示本次操作及影响。确认保存原题库、成员和预期修订，取消不发送该次写请求。归档库仍可查看及恢复，界面禁止收录、换版和移除成员；移出题库只删除整理关系，不删除独立题目或已经使用它的问卷。

## 权限与分页

本步沿用私有题库和题目使用授权，不扩大共享范围。题库所有者可能收录别人共享的题，因此拥有题库并不代表拥有题目编辑、恢复或转授权权限。失效成员在管理页保留整理记录，显示当前不可用，不预览、不换版、不选用；未归档且有效的成员才进入问卷选择列表。失效成员仍可从使用中的题库移除。

题库和成员分别使用后端返回的游标分页，界面保存前一页游标，原样编码后传回。切换使用中与归档筛选会重置题库分页和选择状态，成员翻页不拿题目ID替代成员游标。选择模式按原题目系列过滤时，当前页可能没有符合项；界面保留后续页入口，不把当前页为空解释为整个题库无可选题目。

选择题库条目前，界面再次读取题库详情，核对题库未归档、修订仍与所见一致；再读取该条目指向的具体题目版本，核对当前读取权限及题目、版本身份。发现题库变化时清空候选并要求刷新；读取版本返回404时移除缓存内容及选择，不发出旧版本选择事件。真正保存问卷时仍由后端重新验证使用权、内容及来源。

## 等待、失败和修订冲突

每次写入保存原始方法、路径、请求体和创建键。网络结果不明或503等服务端错误时，界面暂停新决定，只允许原样重试或明确结束本次请求，不自动换一个创建键或修改预期修订。写入已经成功而回读失败时，待处理状态标为已保存，只重新GET题库和成员，不再提交修改。删除请求也按原路径和修订恢复，不能因为成员已被删除就自行判断上次失败。

409不会自动套用新修订重发。界面先读当前题库，展示原决定和当前名称、说明、归档状态；成员决定还要核对目标题目的当前固定版或缺失状态。第一页未找到目标且还有后续页时，不能确认，须继续读取直到找到目标或查到末页。核对页之间的题库修订必须一致，再次变化则重新读第一页。

核对完成后，操作者先明确确认，再单独点击“提交已确认操作”。若服务器状态已经达到原目标，只回读并结束核对，不重复写入；若当前题库已归档或目标成员失去权限，不重新提交成员变更。这个过程保留后端的比较修订语义，没有把读取当前状态等同于批准覆盖当前状态。

父页面合并题库及内层选题器的忙碌状态，并将表单、页内确认、待核对请求和内层窗口纳入离开保护。题库与题目管理互相切换、返回问卷列表、打开其他问卷、创建问卷、退出和刷新均经过相应保护。进入题库页会清空旧问卷编辑上下文，避免保留的编辑入口绕过离开判断。

异步结果同时核对账号令牌、请求代次、题库身份和组件存活状态；内层选择器还有独立操作标识。当前401会通知父页面清除失效会话，旧账号的迟到401或成功响应不能污染新会话。题库选择先完成读取并释放父页面忙碌状态，再发出所选的固定版本，避免父页面因仍在等待而丢弃选择。

## AI使用与后续边界

主代理负责App入口、会话与离开保护集成、审计工具、统一执行和真实浏览器验收；界面代理实现题库组件；测试代理编写题库受控组件测试；复核代理只读检查状态、权限、冲突与选择边界；文档代理依据实际代码和日志整理本说明。恢复代理按精确归属核对并恢复跨日中断的专用环境；主代理发现收录、同系列换版及来源不可读时用途文案不准确，修正后重新运行完整前端和构建，并在真实页面核对题库用途文案与内层Escape关闭。代码、测试、浏览器操作和文档按AI实际产出记录，不虚构用户亲手实现或已经独立掌握。

题库界面承接已有后端能力，不等于跨问卷统计已经实现。本步不迁移真实业务数据，不按题干猜测来源，不自动推送GitHub或提交课程平台。后续仍需完成跨问卷单题统计、使用影响口径复核及第二阶段最终兼容、迁移/回退演练与整体报告。
