## 本步接通的操作

登录后增加“个人题目”入口，可以创建单选、多选、文字、数字四种题型，设置选项及相应边界，查看内容预览、当前版本和历史。列表分页读取，历史可继续加载；版本号表示创建顺序，内容来源可能是更早的任意版本。

“基于此版编辑”以所选版为内容来源，保存时另建版本。“恢复此版内容”调用服务器恢复接口，形成带恢复记录的新版本，不覆盖旧版，也不自动给问卷换版。界面分别展示内容来源与恢复前版本，不能把二者当成同一条历史关系。题目预览中的答案只保留在当前页面，不产生答卷。

使用情况支持“当前草稿/发布快照”和“整个题目系列/当前选定版本”，逐页列出本人问卷及卷内实例。一份问卷的多个发布快照可以各占一行，不能把行数直接称为不同问卷数。这是实时查询，翻页期间可能有新编辑；刷新第一页才能重新核对范围。

本步使用已有私有题接口，没有增加共享授权、题库分组或跨问卷统计，也没有业务数据迁移。个人题目管理不等于课程第二阶段全部功能完成。

## 固定选版、换版与解绑

问卷编辑器增加“从个人题目选用”。用户打开某题、检查具体版本后，点击“选择Vn”将该版本内容及来源加入本地草稿。新实例生成独立卷内ID，默认必答、无条件规则；空问卷以它为入口，原末题默认到结束时将默认去向接到新题。仍需检查问卷结构，保存草稿后再发布。

已有引用的“更换版本”限定同一题目系列，并优先展示本实例当前固定使用的版本；不会因为题目当前版本已更新而默认替换。确认换版只替换 `kind/title/config`和固定版本ID，保留实例ID、必答、默认去向与条件规则。题型、选项或范围改变可能使旧规则不再合法，因此保留规则供检查，由原预览/发布校验给出问题，不能通过清空规则掩盖错误。

“解除引用”保留当前题目内容、必答和跳转，仅移除该实例的来源。它先改变本地草稿，保存后生效；已有发布快照仍保留其来源。仅来源变化也算未保存修改，例如切到内容相同的另一版本、解除引用；保存按钮及离开提醒不能只比较题干定义。

保存时定义与来源仍通过同一草稿修订一起提交；删除实例会去除其映射，无来源旧草稿保持原请求形式。历史复制继续携带所选发布快照的来源或明确的空数组。来源不匹配错误接入既有字段定位和编辑失效机制；手动修改仍绑定的题目不会静默解绑。

## 冲突、重试与会话边界

个人题目的创建、派生、恢复分别保留本次操作标识和完整请求。写入结果不明时锁定内容，并提供原操作重试；若写入已确认、随后读回失败，只重新读取保存结果，不再次创建版本。当前版本冲突需要先读回并确认新的保存依据，再显式执行新操作。

这些待确认状态保存在当前组件内存中；刷新页面、关闭标签页或明确离开会失去原操作重试入口。离开时显示具体提示，不能据此承诺跨设备或页面重载后自动恢复。已保存版本仍可重新登录查询。

等待题目请求时限制相关导航及编辑；返回结果需同时符合当前账号、令牌和组件代次，防止退出或切换后迟到响应覆盖新界面。个人题目和主页面遇到401均清除失效凭据与账号视图。

收集设置更新后的读取只刷新收集状态、政策及对应修订等信息，不接受另一个页面的新草稿修订或来源。发现远端草稿变化时保留本地内容和原保存依据，提示比较并重新载入，阻止直接发布；后续保存仍由服务器修订检查拒绝旧依据，避免设置刷新吞掉冲突。
