# 账号隔离与匿名填写

日期：2026 年 10 月 20 日。范围：多账号视图隔离、非所有者写权限、匿名/实名明细与实际CSV导出。

## 真实复现并修复

旧构建中，A（browser_1020_01）停在统计页；另一同源页面退出后，原页刷新得到401。此时在原页注册并登录B（privacy_1020_02），页面显示B账号、问卷0份，却仍展示A的V1统计110及原始答卷。这是前端缓存暴露；后端管理接口仍会拒绝B的越权请求。

修复如下：

- 退出、401、安装新账号前统一清理管理、编辑、版本、预览、统计、明细、填写、回执与弹窗等内存状态。
- 其他标签页退出或更换令牌时，本页清空视图并提示重新登录；不删除另一页新安装的令牌。
- 用会话代次和发起时令牌校验异步结果。旧成功响应、401、求值、回执或下载晚回时，不能重填新账号状态或触发旧账号下载。
- 未确认提交的sessionStorage记录按问卷和账号保留；清除内存引用后，新账号只恢复自己的记录，旧账号仍可恢复未确认结果。

源码：frontend/src/App.vue、frontend/src/api.ts；新增frontend/tests/session.test.cjs和npm run test:session命令；tests/test_api.py增加1项非所有者写入/公开投影回归。没有修改后端业务代码或增加依赖。
