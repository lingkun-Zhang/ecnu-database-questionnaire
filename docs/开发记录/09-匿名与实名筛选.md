# 匿名与实名筛选

日期：2026年10月20日。本轮完成V4的F01，仅推进填写方式筛选及相应一致性验收；没有继续开发错误定位、设计提示或性能实验。

## 完成的行为

统计页新增“全部填写方式／仅匿名填写／仅实名填写”。统计、明细分页、CSV统一发送respondentType=all/anonymous/named；省略参数仍按all处理，非法值422。后端共用build_response_scope，在MongoDB聚合、分页或CSV读取前过滤anonymous布尔字段，始终保留归属、版本和acceptedSeq边界。

R/V/A/U/S、选项次数、均值及独立参与者均在当前筛选集合中计算。同一账号可以在匿名和实名集合中各出现，因此两类独立人数不能相加；全局asOfSeq也不能当成筛选后的答卷数。空集合份数/次数为0，数字均值为空。

切换填写方式保留上次确认的全局序号，只在点击“刷新范围”时读取新边界。切换时清空旧明细与游标，旧统计、单题明细或导出晚回不能混入新选择。进入另一问卷的统计重置填写方式及单题筛选，退出账号同样重置。

审查发现旧openSurvey(id,'statistics')会沿用上一问卷的单题ID，使新问卷明细404且统计卡片可能为空。本轮修复这一导航问题，新增状态回归，并在真实页面中验证“实名＋单题 → 返回列表 → 另一问卷统计”恢复为全部填写方式和整个问卷。修前问题来自代码审查，不冒充已经做过修前浏览器复现。
