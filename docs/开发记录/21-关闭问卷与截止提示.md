# 关闭问卷与截止提示

日期：2026年10月21日。本轮只处理原清单中的关闭/截止页面，修复两处误导提示，并改进关闭确认。没有修改后端、数据库Schema、依赖或配置；第一阶段仍有交付收尾。

## 实际问题与修复

真实复现：已关闭问卷的邀请页仍显示“已登录，可开始填写”，按钮可点；后台拒绝后该邀请说明依旧错误。已填写完整的旧页面点击确认提交，预检返回SURVEY_CLOSED，却被“还有需要完成或修正的问题”覆盖，误导填写者修改有效答案。

App.vue现在按公开状态显示停止收集原因并禁用新开始；旧邀请页收到关闭/截止拒绝时也更新状态。提交预检没有结果时保留原错误，不新建提交恢复记录、不发送submit、不清空答案。实际服务拒绝仍是权威判断；没有新增轮询或倒计时，已打开页面在下一次服务器交互时获知变更。

关闭改为页面内二次确认，列出具体问卷名和不可重开后果，默认聚焦“取消关闭”，支持Tab循环、Escape和取消按钮。确认绑定显示时的问卷ID/设置修订，切换问卷或退出后不能沿旧确认关闭其他问卷。沿用现有页面样式。

## 环境和操作

[验收工具](../../tests/support/availability_browser.py)使用真实应用、生产构建、随机MongoDB测试库和本机临时端口。真实API只准备1个教学账号、两份V1问卷及各1份匿名历史答卷，原值分别10和20；允许多填，设置修订1、序号1、政策已锁定。关闭、设置截止和填写操作均由浏览器可见控件完成，没有注入页面状态、替换业务响应或改变服务时钟。

服务在真实请求完成后，按独立预期比较四集合全文并原样转发响应。关闭只允许status/settingsRevision/updatedAt变化；设置截止只允许deadlineAt/settingsRevision/updatedAt变化；其他读取和被拒动作必须无写入。历史账号、版本和答卷全文始终保留，既有多填政策不变。
